# 구명보트 문제

## 문제 설명

- 무게 제한이 존재하는 구명보트를 최소한으로 움직여 모든 사람을 구출할 수 있는 방법 계산

## 입력 예시 
 ```python
 people = [70, 50, 80, 50], limit = 100
 people = [70, 80, 50], limit = 100 
 ```
# 실패한 이유
- 스택을 사용하려고 함

# 해결 아이디어
1. 배열 정렬
2. 투 포인터를 활용하여 두 명의 무게가 제한 무게 이하일 시 왼쪽 포인터 이동, 아닐 시 오른쪽 포인터 이동

``` python
def solution(people, limit):
    left = 0
    right = len(people) - 1
    boats = 0

    while left <= right:
        if people[left] + people[right] <= limit:
            left += 1 # 제한 무게 이하일 시 제외
        right -= 1
        boats += 1
    
    return boats

    
```

# 복잡도 계산

## 시간 복잡도 
1. sort() => 2로 계속 나누기 때문에
-> O(n log n) 

2. 투 포인터 탐색
-> O(n)

=> 총 O(n log n)
