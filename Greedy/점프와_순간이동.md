# 점프와 순간 이동 문제

## 문제 설명

- 점프를 할 시 에너지가 소모되거나 에너지 소모없이 이동한 거리 x 2만큼 이동하는 수트의 이동 거리 계산

## 입력 예시 
 ```python
 N = 5
 N = 6 
 N = 5000 
 ```
# 실패한 이유
- 이진법 아이디어 구현 불가

# 해결 아이디어
1. 홀수일 시 에너지 소모가 필요하고 짝수일 시 순간이동 가능
2. 이진법 계산을 이용한 역추적을 통해 계산 가능

``` python
def solution(n):

    energy = 0
    
    while n > 0:
        if n % 2 == 0: # 짝수일 시 (순간이동 가능)
            n //= 2
        
        else: # 홀수일 시 (순간이동 불가)
            n -= 1
            energy += 1

    return energy
```

# 복잡도 계산

## 시간 복잡도 
1. n이 1이 될 때까지 나눔
-> O(n log n) 

=> 총 O(n log n)
