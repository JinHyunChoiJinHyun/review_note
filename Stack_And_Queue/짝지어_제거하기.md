# 짝지어 제거하기 문제

## 문제 설명

- 앞뒤로 이어붙인 문자열이 동일할 시 배열에서 제거

## 입력 예시 
 ```python
 s = "baabaa"	
 s = "cdcd"	 
 ```
# 실패한 이유
- stack의 끝자리와 문자열을 비교하지 못함

# 해결 아이디어
1. stack에 값이 존재하고 배열의 끝 문자열이 해당 문자열과 동일할 시 배열에서 제거
2. stack에 값이 존재하지 않을 시 배열에 문자열 추가
``` python
def solution(s):
    stack = []

    for char in s:
        if stack and char == stack[-1]: # stack의 끝자리와 문자열 비교 => 반복되는 문자열 찾기
            stack.pop()
        else:
            stack.append(char)
    return 1 if not stack else 0
```

# 복잡도 계산

## 시간 복잡도 

1. for문으로 문자열 1회 순회
-> O(n)

=> 총 O(n)
