# 괄호 회전하기 문제

## 문제 설명

- 괄호가 입력된 문자열을 왼쪽으로 회전시켰을 때 올바른 문자열이 되게 하는 갯수 반환

## 입력 예시 
 ```python
 s = "[](){}"	
 s = "}]()[{"	
 s = "[)(]"
 s = "}}}"
 ```
# 실패한 이유
- 스택을 생각하였으나 회전에 대한 개념 부족

# 해결 아이디어
1. 문자열 비교를 위한 함수 코드 작성
2. 왼쪽의 문자열 요소부터 차례로 뒤로 이동시키며 최종 값 반환

``` python
def is_valid(s):
    stack = []
    pairs = {")":"(", "}":"{", "]":"["}

    for ch in s:
        if char in "({[":
            stack.append(ch)
        else:
            if not stack or stack[-1] != paris[ch]:
                return False
            
            stack.pop()

    return not stack

def solution(s):
    count = 0
    n = len(s)

    for i in range(n):
        rotated = s[i:] + s[:i] # [:0]일 시 값이 없음

        if is_valid(rotated):
            count += 1
        
    return count
```

# 복잡도 계산

## 시간 복잡도 

1. 0부터 n-1까지 반복
-> O(n)

2. 문자열 회전 (슬라이싱 + 문자열 덧셈)
-> O(n)

3. 유효성 검사
-> O(n)

회전 n번 x (문자열 회전 O(n) + 유효성 검사 O(n))
=> 총 O(n제곱)
