#  카펫 문제

## 문제 설명

- 갈색과 노란색의 격자의 수를 통해 카펫의 가로와 세로 길이 유추

## 입력 예시 
 ```python
 brown, yellow = 10, 2
 brown, yellow = 8, 1
 brown, yellow = 24, 24
 ```
# 실패한 이유
- 너비 구하는 공식 접근 불가

# 해결 아이디어
1. 너비 * 높이 = brown + yellow 공식을 사용하여 너비와 높이 계산
2. 너비와 높이에서 각각 2씩 제외하고 곱한 값이 yellow와 같은 값일 시 최종 반환

``` python
def solution(brown, yellow):
    total = brown + yellow

    for width in range(3, total + 1): # total값까지 계산
        # height 계산 (약수 계산)
        if total % width != 0: 
            continue

        height = total // width

        if width < height:
            continue
        
        # 노란색 영역 계산
        if (width - 2) * (height - 2) == yellow:
            return [width, height]
    
    return []

```

## 복잡도 계산

# 시간 복잡도 

1. if total % width != 0에서 약수만 탐색
-> O(√total)

=> 총 O(√total)
