# 다음 큰 숫자 계산 문제

## 문제 설명

- 입력 받은 숫자를 변환한 이진수의 1의 갯수와 같은 1의 갯수를 가지는 다음 큰 숫자 반환

## 입력 예시 
 ```python
 n = 78
 ```
# 실패한 이유
- 방법 접근 불가

# 해결 아이디어
1. 입력 받은 숫자 이진수로 변환 후 1 갯수 세기
2. 반복문을 실행하여 입력 받은 숫자에 1씩 더하고 이진수로 변환 후 이전의 값과 비교

``` python
def solution(n):
    count_ones = bin(n).count("1")

    while True:
        n += 1
        if bin(n).count("1") == count_ones:
            return n
```

## 복잡도 계산

# 시간 복잡도 

1. 이진수 변환
-> O(log n)

=> 총 O(log n)

# 공간 복잡도

1. 메모리 사용 거의 없음
-> O(1)

=> 총 O(1)
