# 이진 변환 반복 문제

## 문제 설명

- 이진수의 0을 모두 제거하고 0을 제거한 이진수의 길이를 다시 이진수로 변환을 반복

## 입력 예시 
 ```python
 s = "110010101001"	
 s = "01110"	
 s = "1111111"   
 ```
# 실패한 이유
- 이진수 변환 코드에 대해 알지 못함

# 해결 아이디어
1. 입력 받은 문자열 중 0의 갯수를 세고 0을 공백으로 대체
2. 0을 제거한 문자열의 길이 반환
3. 반환된 길이를 다시 이진수로 변환
4. 1(이진수 중 0이 없는 수)가 될 때까지 반복

``` python
def solution(s):
    count = 0
    removed_zeros = 0

    while s != "1":
        # 0 개수 세기
        zeros = s.count("0")
        removed_zeros += zeros

        s = s.replace("0", "")

        # 길이 반환 후 이진수로 변환
        length = len(s)
        s = bin(length)[2:] # 이진수로 변환 후 index 2부터 출력

        count += 1
    
    return [count, removed_zeros]

```

# 복잡도 계산

## 시간 복잡도 

1. while문 처음 실행 => 문자열만큼 bin 코드 실행
-> O(n)
2. 각 반복마다 문자열 감소
-> O(log n)

=> 총 O(n)

## 공간 복잡도

1. 입력 문자열 크기에 비례
-> O(n)

=> 총 O(n)
