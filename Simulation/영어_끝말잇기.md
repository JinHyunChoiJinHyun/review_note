# 영어 끝말잇기 문제

## 문제 설명

- 영어 끝말잇기의 규칙을 위반한 사람의 순서와 차례 반환

- 1번부터 번호 순서대로 한 사람씩 차례대로 단어를 말합니다.

- 마지막 사람이 단어를 말한 다음에는 다시 1번부터 시작합니다.

- 앞사람이 말한 단어의 마지막 문자로 시작하는 단어를 말해야 합니다.

- 이전에 등장했던 단어는 사용할 수 없습니다.

- 한 글자인 단어는 인정되지 않습니다.

## 입력 예시 
 ```python
 n = 3, words = ["tank", "kick", "know", "wheel", "land", "dream", "mother", "robot", "tank"]

 n = 5, words = ["hello", "observe", "effect", "take", "either", "recognize", "encourage", "ensure", "establish", "hang", "gather", "refer", "reference", "estimate", "executive"]

 n = 2, words = ["hello", "one", "even", "never", "now", "world", "draw"]  
 ```
# 실패한 이유
- 이전의 사용 여부 검토를 위해 스택을 사용하려고 함

# 해결 아이디어
1. set() 함수를 사용하여 빠르게 사용 여부 검토
2. 반복문을 사용하여 끝 글자와 앞 글자 비교

``` python
def solution(n, words):
    used = set()

    for i in range(len(words)):
        word = words[i]

        # 단어 길이 검토
        if len(word) == 1:
            return [(i % n) + 1, (i // n) + 1]

        # 단어 규칙 성립 여부 검토
        if i > 0 and words[i - 1][-1] != word[-1]: # i가 0일 시 오류 발생
            return [(i % n) + 1, (i // n) + 1]

        # 중복 여부 검토
        if used in word:
            return [(i % n) + 1, (i // n) + 1]
    
        used.add(word)
    
    # 문제가 없을 시

    return [0, 0]

```

# 복잡도 계산

## 시간 복잡도 

1. 길이 확인
-> O(1)
2. 끝 글자 비교
-> O(1)
3. 중복 단어 확인 <- set 사용으로 매우 빠름
-> O(1)
4. 단어 추가
-> O(1)

=> 총 O(n)
