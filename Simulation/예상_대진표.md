# 예상 대진표 문제

## 문제 설명

- A와 B가 토너먼트에서 계속해서 승리할 시 몇번째 경기에서 만나는지 계산

## 입력 예시 
 ```python
 n = 8, a = 4, b = 7   
 ```
# 실패한 이유
- 다음 부여 받는 번호 계산 공식 모름

# 해결 아이디어
1. 승리할 시 다음 게임에 부여받는 번호 계산 후 라운드 수 카운트
2. A와 B의 번호가 같을 시 라운드 수 반환

``` python
def solution(n, a, b):
    
    round = 0

    while a != b:
        # 같은 조끼리 다음 번호가 같도록 +1 계산 (0부터 시작할 시 +1 없이 //2만 해도 무방)
        a = (a + 1) // 2
        b = (b + 1) // 2
        round += 1

    return round

```

# 복잡도 계산

## 시간 복잡도 

1. 반복문 진행할수록 a,b가 절반씩 감소
-> O(log n)

=> 총 O(log n)
