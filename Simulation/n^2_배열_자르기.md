# n^2 배열 자르기 문제

## 문제 설명

- left부터 right까지의 배열 반환

## 입력 예시 
 ```python
 N = 3, left = 2, right = 5
 N = 4, left = 7, right = 14
 ```
# 실패한 이유
- 전체 배열을 만들려고 함
    
# 해결 아이디어
1. 반복문을 사용하여 범위 내의 값을 순서대로 나열
2. row와 col 중 최댓값에 1을 더해 값 반환

``` python
def solution(n, left, right):
    
    for index in (left, right + 1):
        row = index // n # 앞쪽부터 순서대로 나열 -> 나눗셈
        col = index % n # 나머지만큼 이동 -> 나머지만큼 이동
        
        result.append(max(row, col) + 1) # row와 col 중 최댓값에 1을 더해주면 해당 위치의 숫자 반환
    return result

```

# 복잡도 계산

## 시간 복잡도 
1. 반복문만큼 작용
-> O(right - left + 1) 

=> 총 O(n)
