# 숫자의 표현 문제

## 문제 설명

- 자연수 n을 연속한 자연수들로 표현 하는 방법의 수 계산

## 입력 예시 
 ```python
 n = 15
 ```
# 실패한 이유
- 등차 수열에 대한 이해 부족

# 해결 아이디어
1. 가상의 수열에서 start와 end 포인터를 조금씩 이동시키며 가상의 수를 반복해서 더함 (등차수열)
2. 자연수 n과 반복해서 더한 가상의 수가 같으면 count 1 증가

``` python
def solution(n):
   count = 0
   start = 1
   end = 1
   current_sum = 1 # 가상의 등차수열

   while start <= n //2:
    if current_sum == n:
        count += 1
        current_sum -= start # start 포인터 이동 (이전의 숫자 제거)
        start += 1
    elif current_sum <= n:
        end += 1
        current_sum += end # 하나씩 증가하는 end 값을 더함으로써 등차수열과 비슷한 형태가 됨

    else:
        current_sum -= start 
        start += 1
return count + 1 # 본인도 포함
```

# 복잡도 계산

## 시간 복잡도 

1. end는 n까지 한번씩 증가
-> O(n)

=> 총 O(n)

## 공간 복잡도

1. 배열 사용 안 함
-> O(1)

=> 총 O(1)
