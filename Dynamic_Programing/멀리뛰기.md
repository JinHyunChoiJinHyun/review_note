# 멀리뛰기 계산 문제

## 문제 설명

- 최대 2칸까지 뛸 수 있을 때 입력된 칸의 숫자에 도달하는 방법이 몇가지인지 계산

## 입력 예시 
 ```python
 n = "4"	
 n = "3"	 
 ```
# 실패한 이유
- 피보나치 수열 활용 부족

# 해결 아이디어
1. 피보나치 수열 활용

``` python
def solution(n):
   a, b = 1, 2

   for _ in range(3, n + 1):    
    a, b = b, (a + b) % 1234567

   return b if n > 1 else 1 # n = 1 일 시 반복문 오류 발생 대비를 위한 오류 처리

```

# 복잡도 계산

## 시간 복잡도 

1. 반복문 n-2번 실행
-> O(n)

=> 총 O(n)
