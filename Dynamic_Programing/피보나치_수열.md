# 피보나치 수열 계산 문제

## 문제 설명

- 피보나치 수의 배열 중 n번째 숫자를 1234567로 나눈 값의 나머지 반환

## 입력 예시 
 ```python
 n = "3"	
 n = "5"	 
 ```
# 실패한 이유
- 피보나치 수열에 대한 이해 부족

# 해결 아이디어
1. 피보나치 수열 배열에 저장
2. 해당 배열의 수를 1234567로 나눈 값의 나머지 반환
``` python
def solution(n):
    fib = [0] * (n+1) # 배열 생성
    fib[0] = 0
    fib[1] = 1

    for i in range(2, n+1):
        fib[i] = (fib[i-1] + fib[i-2]) % 1234567

    return fib[n]
```

# 복잡도 계산

## 시간 복잡도 

1. 2부터 n까지 반복
-> O(n)

=> 총 O(n)

## 공간 복잡도

1. n+1 리스트를 사용
-> O(n)

=> 총 O(n)
