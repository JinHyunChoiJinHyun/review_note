# 행렬의 곱셈 문제

## 문제 설명

- 2차원 행렬을 입력 받아 arr1에 arr2를 곱한 결과를 반환

## 입력 예시 
 ```python
 arr1 = [[1, 4], [3, 2], [4, 1]], arr2 = [[3, 3], [3, 3]]
 arr1 = [[2, 3, 2], [4, 2, 4], [3, 1, 4]], arr2 = [[5, 4, 3], [2, 4, 1], [3, 1, 1]]
 ```

# 실패한 이유
- 행렬 곱셈에 대한 이해 부족

# 해결 아이디어
1. arr1의 행 반복
2. arr2의 열 반복
3. 곱한 후 덧셈

