# 연속 부분 수열 합의 개수 계산 문제

## 문제 설명

- 원형 수열의 연속하는 부분 수열의 합으로 만들 수 있는 수의 가지 수 계산

## 입력 예시 
 ```python
 elements = [7,9,1,1,4] 
 ```
# 실패한 이유
- 원형 수열 계산식에 대해서 모름

# 해결 아이디어
1. 원형 수열을 선형 수열로 변환
2. 반복문을 사용해 1개부터 n개까지의 연속하는 요소의 합 반환

# 단순 for문 반복
``` python
def solution(elements):
    n = len(elements)
    extended = elements * 2 # 원형 수열을 선형 수열로 변환
    result = set()

    for length in range(1, n+1):
        for start in range(n):
            part_sum = sum(extended[start:start + length]) # 각 요소의 개수별 합 반환

            result.add(part_sum)
    
    return len(result)
    
```

# 슬라이딩 윈도우 사용
``` python
def solution(elements):
    n = len(elements)
    extended = elements * 2 # 원형 수열을 선형 수열로 변환
    result = set() # 중복 자동 제거

    for length in range(1, n+1):
        window_sum = sum(extended[0:length]) # 처음 윈도우 합 계산 모든 요소의 경우의 수 계산
        result.add(window_sum)

        for i in range(1, n):
            window_sum = window_sum - extended[i-1] + extended[i+length-1] # 슬라이드 한칸씩 이동 -> 이전의 수 제거, 다음 수 추가
            result.add(window_sum) # window_sum 지속 누적 // result = {13, 16, 11, 15, 14}              
    
    return len(result)
    
```

# 복잡도 계산

## 시간 복잡도 
1. sort() => 2로 계속 나누기 때문에
-> O(n log n) 

2. 투 포인터 탐색
-> O(n)

=> 총 O(n log n)
