# 할인 행사 계산 문제

## 문제 설명

- 자신이 원하는 제품과 수량이 할인하는 날짜와 10일 연속으로 일치할 경우에 맞춰 회원 가입 진행 시 가능한 경우의 수

## 입력 예시 
 ```python
 want = ["banana", "apple", "rice", "pork", "pot"], number = [3, 2, 2, 2, 1], discount = ["chicken", "apple", "apple", "banana", "rice", "apple", "pork", "banana", "pork", "rice", "pot", "banana", "apple", "banana"]

 want = ["apple"], number = [10], discount = ["banana", "banana", "banana", "banana", "banana", "banana", "banana", "banana", "banana", "banana"]
 ```
# 실패한 이유
- 배열의 요소를 하나하나 비교하여 dictionary에 넣으려고 함

# 해결 아이디어
1. 원하는 물품과 숫자를 dict 형태로 저장
2. Count 함수와 반복문을 사용하여 차례로 10개 요소의 중복 횟수 비교
``` python
from collections import Counter

def solution(want, number, discount):
    total_days = 0
    want_dict = dict(zip(want, number))    

    for i in range(len(discount) - 9):
        window = discount[i:i+10]
        window_counter = Counter(window) # 중복 갯수 카운트 후 dict 형태로 반환

        if all(window_counter[item] == want_dict.get(item, 0) for item in want_dict): # all() 함수 => 모든 요소가 조건에 만족할 시 true 반환 // value끼리 서로 비교

            total_days += 1
    
    return total_days
```

# 복잡도 계산

## 시간 복잡도 

1. 윈도우 루프 횟수 0부터 N - 10까지
-> O(n)

2. 각 윈도우 내 작업 (리스트 슬라이싱, 빈도 계산, all 비교)
-> O(10)

3. 전체 반복 내 연산
-> O(1)

=> 총 O(n)
